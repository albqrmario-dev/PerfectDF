# PerfectDF interface

A document workbench, with the PDF as the main surface. The brand is a compact paper monogram; the rest of the interface stays quiet.

Tokens: paper #ffffff, desk #f1f3f5, ink #242b33, secondary #637080, rule #dce1e6, blue #285ec8. Source Sans 3 for both interface and headings, with tabular numerals for page controls. No decorative gradients or entrance animation.

Desktop layout:

    [mark + name]                         [privacy] [open PDF]
    [tool families] [document / empty page] [current tool]
    [visible tools] [preview and controls] [settings + action]
    [source links]  [document status                     ]

Mobile: header, horizontally scrollable families, visible tool buttons, settings, then document. Keep controls in normal flow, with no overlay covering the PDF.

Review: a marketing hero or repeated tool cards would obscure this editor's primary job. Use a single paper illustration only in the empty workspace. Categories expand into direct actions; remove the duplicated action selector from the settings. Use concrete action names, plain guidance and a real form editor instead of asking people to write JSON.
